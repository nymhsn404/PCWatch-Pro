# 🖥️ PCWatch Pro

**A Local PC Activity & Security Monitor for Windows**

PCWatch Pro is a Windows application with a local web dashboard for reviewing PC activity and security-related events.

## Features

- Live keyboard and mouse activity monitoring
- Active window and process tracking
- USB connection and disconnection events
- Network connections and system power events
- Security dashboard for login and lock events
- Available historical activity imports
- Local SQLite database storage
- Dark terminal-style web dashboard

## Download

**[Download PCWatch Pro — Latest Release](../../releases/latest)**

1. Download `pcwatch.exe` from the latest release.
2. Save it to your Windows PC.
3. Run it with administrator privileges if required.
4. Open `http://127.0.0.1:8765` in your browser.

## Privacy

PCWatch Pro is intended for authorized, local PC monitoring. Review its permissions and data collection behavior before use. Do not use it to monitor other people without appropriate authorization and consent.
